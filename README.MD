# Enterprise AI Sales & Inventory Forecasting Copilot 📈

An interactive data-driven dashboard built with Python and Streamlit to monitor sales trends, track inventory levels, and provide dynamic reorder alerts.

## Features
- **Key Performance Indicators (KPIs):** Real-time monitoring of total sales, average stock levels, and daily sales performance.
- **Interactive Visualizations:** Historical sales trend charts and stock level breakdown powered by Plotly.
- **Inventory Alerts & Forecasting:** Automatic low-stock warnings based on moving average sales data.

## Tech Stack
- **Language:** Python
- **Framework:** Streamlit
- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Plotly
